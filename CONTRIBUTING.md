# Contributing to arta-node

Thanks for your interest in the Arta node client.

## Current status

This project is in early architecture/design phase (see [README](./README.md)). Contributions
at this stage are most useful as:

- Feedback on the [architecture draft](./docs/architecture.md)
- Design proposals via [arta-improvement-proposals](https://github.com/artablok/arta-improvement-proposals)
- Discussion in [Issues](https://github.com/artablok/arta-node/issues)

## Code contributions

Once implementation begins, this document will be updated with build instructions, coding
standards, and a PR checklist.

## Code of conduct

Be respectful. Technical disagreements are welcome; personal attacks are not.
